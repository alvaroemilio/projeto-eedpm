#Projeto Escolar

Projeto Desenvolvido por Meus Alunos do Curso Técnico em Informática

Este projeto foi desenvolvido pelos alunos do Curso Técnico em Informática da turma de Inimutaba, Minas Gerais, com o objetivo de criar uma plataforma digital informativa e acessível para a comunidade escolar.

O site tem como finalidade destacar as principais informações da escola, facilitando o acesso dos estudantes, responsáveis e visitantes aos conteúdos institucionais. Além disso, a plataforma apresenta de forma organizada as disciplinas ministradas e os cursos ofertados no turno noturno, contribuindo para a divulgação das oportunidades educacionais disponibilizadas pela instituição.

Por meio deste projeto, os alunos aplicaram conhecimentos adquiridos durante o curso técnico, envolvendo áreas como desenvolvimento web, design de interfaces e organização de informações, promovendo uma solução tecnológica voltada para a melhoria da comunicação escolar.
